# FERRO831 E-Commerce Website

A custom PHP + MySQL MVC-based e-commerce web application built to understand real-world online store architecture.

## Features

- Product listing
- Product details
- Cart
- Wishlist
- Checkout
- User profile
- Address management
- Order history
- Admin dashboard
- Product management
- Variants/SKUs
- Inventory management
- Order status tracking

## Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Custom MVC architecture
- XAMPP
- Hostinger deployment target

## Folder Structure

- app/
- core/
- config/
- assets/
- admin/
- user/
- docs/

## Local Setup

1. Clone the repository.
2. Copy `config/db.example.php` to `config/db.php`.
3. Create a MySQL database.
4. Import the database schema manually.
5. Run using XAMPP.
